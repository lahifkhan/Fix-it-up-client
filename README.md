# FixItUp

**Live Site URL:** [https://tangerine-platypus-2af136.netlify.app]

## Overview

FixItUp is a community-driven platform designed to help people report, fund, and resolve local issues together. It connects citizens who identify problems in their area with others who want to contribute toward fixing them, building a cleaner and more responsible community.

## Features

- **User Authentication:** Secure login and registration system using Firebase Authentication.
- **Issue Management:** Users can easily add new issues, view all community issues, and track their own submissions.
- **Community Contribution:** Allows users to contribute funds to fix issues and view total contributions.
- **Theme Toggle:** Light and dark mode support powered by DaisyUI for better user experience.
- **Responsive UI:** Fully optimized for mobile, tablet, and desktop devices.
